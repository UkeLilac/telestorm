BACKROOMS // hunt  —  游戏介绍
=====================================
必须用本地服务器打开:
 1. 在本文件夹打开终端 (先 cd 进这个文件夹!)
 2. 运行:  python -m http.server 8000
 3. 浏览器访问:  http://localhost:8000
     (应直接进入黑底 BACKROOMS 界面)
文件清单(必须在同一文件夹):
  index.html, IDLE.fbx, WALK.fbx, RELAX.fbx, SIT.fbx

操作:WASD 移动 / 鼠标视角 / Shift 跑 / ESC 释放鼠标
目标:收集全部磁带。每收一盘,怪物提速。被怪物追到 2.4 米内即失败。

游戏机制：
 1.注视怪物增加故障值，故障值超高阈值则结束
 2.地图内有传送门
 3.消耗磁带可以使得时间回溯五秒（怪物和人都会倒退回到5s前的位置，不是瞬移到五秒前位置，是移动退回）

可调参数(开始界面):
  FLOOR SIZE 14-40    地图大小
  WALLS 8-28          墙的数量(越大越像迷宫,越小越空旷)
  TAPES TO COLLECCT x 由前两个参数决定
