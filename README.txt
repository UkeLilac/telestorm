BACKROOMS // hunt  —  本地运行说明
=====================================
浏览器禁止 file:// 读取本地 FBX 模型,必须用本地服务器打开:

  1. 在本文件夹打开终端 (先 cd 进这个文件夹!)
  2. 运行:  python -m http.server 8000
  3. 浏览器访问:  http://localhost:8000
     (应直接进入黑底 BACKROOMS 界面;若看到文件列表,说明没 cd 对目录)

文件清单(必须在同一文件夹):
  index.html, IDLE.fbx, WALK.fbx, RELAX.fbx

操作:WASD 移动 / 鼠标视角 / Shift 跑 / ESC 释放鼠标
目标:收集全部磁带。每收一盘,怪物提速。被怪物追到 2.4 米内即失败。

本次改动:
- 单层平面后室(不再有楼层,彻底消除怪物穿模/隔空抓人)
- 约 70% 开阔,长墙段 + 零星柱子,地面/天花/网格线
- 墙高 = 人的 2 倍;怪物身高 = 人的 1.45 倍(高于人、矮于墙)
- 抓人判定只看水平距离;怪物脚永远贴地
- 长时间找不到你时怪物会坐下(RELAX),你靠近再起身追

可调参数(开始界面):
  FLOOR SIZE 14-40  地图大小
  WALLS 8-28        墙的数量(越大越像迷宫,越小越空旷;默认18≈70%开阔)
